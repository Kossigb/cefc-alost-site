⚙️ Paramètres

Connexion GitHub, compte et données

🔑 Token GitHub (requis pour sauvegarder) ⚠ Non configuré

Pour que vos modifications soient publiées directement sur le site, vous devez connecter un Personal Access Token (PAT) GitHub.
Ce token est stocké uniquement dans votre navigateur.

📋 Comment créer un token :
  1. Allez sur github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Cliquez Generate new token
  3. Nom : CEFC Admin — Expiration : No expiration (ou 1 an)
  4. Repository access : Only select repositories → choisissez cefc-alost-site
  5. Permissions → Repository permissions → Contents : Read and write
  6. Cliquez Generate token et copiez le token affiché
